# EasyShelf

A floating, draggable shelf of one-click buttons for the Blender 3D Viewport, UV Editor and Node Editor, plus an optional radial pie menu on a hotkey. Free and open source (GPL-3.0-or-later).

- Website: https://easyshelf-addon.github.io/EasyShelf/
- Install: [extensions.blender.org/add-ons/easy-shelf](https://extensions.blender.org/add-ons/easy-shelf/) (in Blender: Preferences > Get Extensions). Zips of each version are on [Releases](https://github.com/easyshelf-addon/EasyShelf/releases/latest).
- Requires Blender 4.2 or newer.

Source code of the add-on is in [`addon/`](addon), the website is in [`docs/`](docs).

# EasyShelf (RU)

Плавающая панель кнопок быстрого доступа во вьюпорте, UV- и Node-редакторе Blender и радиальное пай-меню на хоткей. Бесплатно, открытый код (GPL-3.0-or-later). Установка: Preferences > Get Extensions > Install from Disk, нужен Blender 4.2+.
